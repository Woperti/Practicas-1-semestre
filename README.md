## ✅ Reglas generales (aplican a todas las prácticas)

- Las prácticas **se hacen y se entregan en clase**, salvo que la práctica indique otra cosa.
- El entregable es **un enlace** de Excel Online o Word Online guardado en tu **OneDrive**, con permiso de solo lectura.
- Debes tener tu **cuenta de OneDrive lista antes de la clase** (los pasos están en la Práctica 1).
- Se permite consultar IA, pero **debes poder explicar tu propio trabajo**. Si no puedes, no cuenta.
- Los datos de cada práctica dependen de tu **número de lista**. Los archivos con datos iguales se anulan.
- Nombre de archivo: `Grupo_Lista_Apellido_Nombre_P##` (ej. `2B_17_Perez_Ana_P01`).
